# ADR 0005: 工作区路径约束与审批门禁 (Approval Gate)

## 状态
已接受 (Accepted)

## 背景与决策
为确保团队级分发中的安全合规，防止 Agent 在执行任务时因幻觉或误操作导致关键文件损毁或机密泄露，我们决定：
1. Rust 宿主对 Sidecar 的工作目录施加路径作用域限制（Workspace Jail）；
2. 对高危操作（如 Shell 危险指令、外部跨域网络请求、非临时文件删除）实施 Approval Gate 交互拦截，由用户在客户端明确确认后方可继续执行。

## 权衡与后果
* **优势**：保障企业代码与主机安全，降低团队全员上手风险。
* **代价**：Agent 在执行敏感工具时需要暂停并挂起等待 IPC 交互回调，需完善超时处理与状态恢复逻辑。
