# ADR 0002: 基于 Stdio 的 JSON-RPC 进程间通信

## 状态
已接受 (Accepted)

## 背景与决策
Tauri 主进程与 Node.js Sidecar 之间需要进行高频、低延迟、支持流式传输与双向交互（如打断、用户授权确认）的通信。为避免本地端口冲突、防火墙拦截与安全提权问题，我们决定采用 Stdio（标准输入输出）管道承载 JSON-RPC 2.0 / NDJSON 协议。

## 权衡与后果
* **优势**：零本地端口占用，生命周期与父子进程紧密绑定，天然具备最高安全隔离性。
* **代价**：Rust 端与 Node 端需各自实现基于换行符的流式分帧解析器（NDJSON Framing），且无法直接通过外部 Web 浏览器抓包调试。
