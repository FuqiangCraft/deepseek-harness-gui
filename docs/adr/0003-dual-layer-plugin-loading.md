# ADR 0003: 双层插件加载与分发机制

## 状态
已接受 (Accepted)

## 背景与决策
为了在享受官方基线更新红利的同时，支持企业/团队定制能力的快速迭代与下发，我们决定采用双层插件加载架构：
1. 官方核心工具与基础适配器作为内置层（Built-in Layer）打包在客户端中；
2. 团队专属能力作为动态层（Dynamic Plugin Layer），通过 `~/.harness/plugins/` 及项目级配置 `cordis.yml` 在运行时动态解析载入。

## 权衡与后果
* **优势**：官方 Harness 内核与企业定制插件完全解耦，团队插件更新无需重新分发桌面客户端安装包。
* **代价**：Sidecar 启动器需要增加动态模块路径（`NODE_PATH` / CJS / ESM Loader）的探测与安全沙箱路径校验逻辑。
